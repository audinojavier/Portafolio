# Portafolio profesional

Portafolio web estático preparado para publicar con **GitHub Pages**.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Google Fonts
- GitHub Pages

## Estructura

```text
portfolio/
├── index.html
├── assets/
│   ├── css/style.css
│   ├── js/script.js
│   └── img/
├── cv/
│   └── CV.pdf
└── README.md
```

## Personalización

Antes de publicar, reemplaza:

1. `tu-correo@ejemplo.com` por tu correo.
2. Los enlaces `https://github.com/` y `https://www.linkedin.com/` por tus perfiles.
3. Los enlaces `#` de los proyectos por las URLs reales de tus repositorios.
4. `cv/CV.pdf` por tu CV.
5. El bloque visual de la portada por una fotografía profesional si lo deseas.
6. Los textos de proyectos por los datos definitivos.

## Publicar en GitHub Pages

1. Crea un repositorio llamado `TU_USUARIO.github.io`.
2. Copia todos los archivos de este proyecto al repositorio.
3. Haz commit y push a la rama `main`.
4. En GitHub entra a **Settings → Pages**.
5. Selecciona **Deploy from a branch**.
6. Selecciona `main` y la carpeta `/root`.
7. Guarda los cambios.

Tu sitio quedará disponible en:

`https://TU_USUARIO.github.io/`
